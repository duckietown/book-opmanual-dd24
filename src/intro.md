# The Duckiedrone Operation Manual

```{warning}
🚧 This manual documents the _ente_ software version of the Duckiedrone DD24-B and is still a work in progress. 🚧

The current stable release is the [_daffy_ Duckiedrone operation manual](https://docs.duckietown.com/daffy/opmanual-dd24/intro.html).
```

Welcome to the Duckiedrone DD24-B operation manual. The Duckiedrone is a do-it-yourself (DIY) Raspberry Pi-based autonomous quadcopter.

The Duckiedrone DD24-B is the third hardware iteration of the Duckiedrone. For information about its predecessors, see the DD18 and DD21 Duckiedrone manuals.

This manual provides instructions for assembling, testing, initializing, calibrating, operating, and programming a Duckiedrone DD24-B. It also describes learning experiences that use the Duckiedrone.
